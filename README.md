# Traffic Flow Forecasting on Bay Area Freeways

ML course project, Topic 4: Traffic Prediction (IIIT Bangalore).
Forecasts freeway flow 15 and 60 minutes ahead for 100 Bay Area sensors
(LargeST dataset, 2017-2019).

## Setup
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

Data files are not stored in Git. Put them in data/ (shared Drive folder traffic_project/data).
